# Coral Club — OKR Tree Builder

Живая версия: bundle.202608050711.js (версия сборки указана в имени файла — при каждом обновлении
имя меняется, это исключает показ старой версии из кэша браузера).

## Как обновить

1. Правки — в OKR_Tree_Builder.jsx.
2. npm install && npm run build — пересобрать bundle.js.
3. Переименовать bundle.js в bundle.<новая-версия>.js и обновить путь в index.html.
4. Закоммитить и запушить — GitHub Pages/Netlify опубликуют сами.
